# Точно в ответ!

Игра для тренировки умножения и деления.

- Умножение: мишень 10 × 10, преимущественно сложные примеры.
- Деление без остатка: восемь вариантов ответа от 2 до 9.
- Раунды по 10 примеров, счёт попаданий и промахов, звук по желанию.

Игра работает в браузере без установки и внешних зависимостей. Для локального запуска откройте `index.html`.

GitHub Pages публикует корневую папку ветки `main`. Для обновления игры измените `index.html` и отправьте изменения в эту ветку.
